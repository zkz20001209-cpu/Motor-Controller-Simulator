# Motor Controller Simulator

A lightweight C++17 command-line simulator for 8-axis motor control, homing, alarms, and position limits.

## 项目概述

这是一个 C++ 命令行电机控制模拟器。支持 8 个轴，各轴独立记录使能、报警、运动、位置和回零状态。

程序使用 `AxisStatus axes[8]` 保存各轴状态。`main()` 负责菜单调度，动作函数负责状态变化，`CanMove()` 负责运动前检查。

## 更新说明

- 使用 `AxisStatus` 结构体统一管理每个轴的编号和状态。
- 将使能、禁用、报警、复位及回零操作集中到对应函数。
- 由 `CanMove()` 统一检查运动参数、当前状态和软件限位。
- 触发报警时自动禁用轴并清除回零标记；报警期间禁止重新使能。
- 复位报警后需重新使能、回零，才能执行移动。
- 状态显示和移动校验函数通过 `const` 引用读取状态。
- 位置更新在 `MoveMotor()` 内完成，再清除 busy 并输出完成提示，菜单不再重复更新位置。

程序启动时选中 1 号轴；所有轴默认使能、无报警、空闲、位置为 0，但均未回零。**位置为 0 不代表已经回零，移动前必须先执行菜单 `8`。**

## 功能

- 选择 1～8 号轴，各轴状态相互独立。
- 使能或禁用当前轴，触发和复位当前轴报警；报警期间禁止重新使能。
- 回零：将当前轴位置设为 0，并标记为已回零。
- 支持 `forward`（正向）和 `reverse`（反向）运动，接收速度与步数参数。
- 移动前检查方向、速度、步数、报警、使能和回零状态。
- 目标位置限制为 `-1000`～`1000`，包含两个边界；超限指令不执行。
- 一次查看全部轴的位置、运动、使能、报警和回零状态。
- 触发报警时同时禁用当前轴并清除回零状态；复位报警后需要重新使能和回零。

## 控制菜单

输入菜单数字并按回车。选择 `3` 或 `7` 后，还需要输入对应参数；当前程序不额外显示参数输入提示。

| 命令 | 功能 | 后续输入或效果 |
| --- | --- | --- |
| `1` | 使能当前轴 | 有报警时拒绝使能；无报警时允许在其他条件满足后回零和移动 |
| `2` | 禁用当前轴 | 阻止回零和移动 |
| `3` | 移动当前轴 | 输入 `方向 速度 步数`，例如 `forward 100 500` |
| `4` | 触发报警 | 设置报警、禁用轴，并清除已回零标记 |
| `5` | 复位报警 | 清除报警和已回零标记，不自动使能 |
| `6` | 查看全部轴 | 显示 Position、Busy、Enabled、Alarm、Homed |
| `7` | 选择轴 | 输入 `1`～`8`；无效轴号不会切换当前轴 |
| `8` | 回零 | 已使能且无报警时，将位置置 0 并设置已回零标记 |
| `0` | 退出 | 结束程序 |

## 状态与控制规则

| 状态 | 含义 | 初始值 |
| --- | --- | --- |
| `id` | 轴编号 | `1`～`8` |
| `position` | 当前模拟位置 | `0` |
| `Enable` | 是否使能 | `true` |
| `Alarm` | 是否报警 | `false` |
| `busy` | 是否正在执行运动 | `false` |
| `homed` | 是否已回零 | `false` |

菜单 `6` 中的布尔状态用 `0`（否）和 `1`（是）显示。运动同步完成，`busy` 在运动函数内短暂设为 `true`，结束时恢复为 `false`，因此回到菜单后通常显示空闲。

回零要求当前轴已使能且无报警。移动还要求该轴已经回零、方向有效、速度和步数均为正整数，且目标位置不超限。正向移动增加位置，反向移动减少位置。

`TriggerAlarm()` 将 `Alarm` 设为 `true`、`Enable` 设为 `false`、`homed` 设为 `false`。`ResetAlarm()` 清除报警和回零标记，但不改变使能状态，因此由报警造成的禁用会继续保留。报警期间执行菜单 `1` 会提示 `Motor Alarm`，保持禁用。

恢复顺序为 **`5` 复位报警 → `1` 使能 → `8` 回零 → `3` 移动**。触发和复位报警都不直接改变位置。即使当前没有报警，执行菜单 `5` 也会清除回零标记。单独禁用、重新使能和切换轴不会清除已保存的回零状态。

## 编译与运行

项目源码为 `main.cpp`，无需第三方库，使用支持 C++17 的编译器即可。

### 使用 g++

```bash
g++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o motor_controller_simulator
./motor_controller_simulator
```

Windows PowerShell 下可使用：

```powershell
g++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o motor_controller_simulator.exe
.\motor_controller_simulator.exe
```

### 使用 Visual Studio

1. 安装“使用 C++ 的桌面开发”工作负载。
2. 创建 C++ 控制台项目，用仓库中的 `main.cpp` 替换模板源文件，避免保留两个 `main()`。
3. 在项目属性中将 C++ 语言标准设置为 C++17，符合模式设为“是”（`/permissive-`），并添加 `/utf-8` 选项。源码使用标准替代运算符 `and` / `or`；本次 MSVC 验证需要符合模式才能识别。生成项目后按 `Ctrl+F5` 运行。

如果本地已经配置了 `Motor-Controller-Simulator.sln`，可直接打开该解决方案。当前仓库尚未包含本地生成的 `.sln` 和 `.vcxproj` 文件；仅克隆源码并以文件夹方式打开，不会自动创建传统 VS 控制台项目。

## 操作示例

以下代码块均为按顺序输入的内容，每行输入后按回车。

### 回零后正向移动

```text
8
3
forward 100 500
6
0
```

1 号轴先回零，再正向移动 500 步，最终位置为 `500`，`homed` 为 `1`。菜单 `6` 显示全部轴状态，`0` 退出。

### 切换轴并反向移动

```text
7
2
8
3
reverse 100 200
6
0
```

选择 2 号轴，回零后反向移动 200 步，2 号轴位置为 `-200`，其他轴不受影响。

### 报警后的恢复流程

```text
8
4
1
5
8
1
3
forward 100 100
8
3
forward 100 100
0
```

触发报警后执行 `1` 会提示 `Motor Alarm`，轴保持禁用。执行 `5` 复位后，直接执行 `8` 会提示 `Motor Disable`；执行 `1` 重新使能后，第一次移动仍提示 `Motor Not Homed`。再次执行 `8` 回零，第二次移动成功，位置变为 `100`。

### 验证软件限位

```text
8
3
forward 100 1000
3
forward 100 1
6
0
```

第一次移动到允许的边界 `1000`；第二次移动的目标为 `1001`，提示 `Limit Error`，位置仍为 `1000`。

## 常见提示

| 提示 | 含义与处理 |
| --- | --- |
| `Motor Not Homed` | 当前轴未回零，先执行 `8` |
| `Motor Alarm` | 当前轴有报警，按 `5` 复位、`1` 使能、`8` 回零的顺序恢复 |
| `Motor Disable` | 当前轴未使能，先执行 `1`；若未回零，还需执行 `8` |
| `Direction Error` | 方向只能输入小写 `forward` 或 `reverse` |
| `Speed Error` / `Steps Error` | 速度或步数不大于 0，请输入正整数 |
| `Limit Error` | 目标位置超出 `[-1000, 1000]`，调整方向或步数 |
| `Axis Error` | 轴号不在 1～8 范围内 |
| `Menu Error` | 菜单数字无效，请输入 0～8 |
| `Home Complete` | 回零成功，位置已设为 0 |
| `Move Complete` | 本次模拟运动执行完成 |

## 程序结构

| 函数 | 职责 |
| --- | --- |
| `CurrentAxis` | 根据当前轴号返回结构体数组中对应轴的引用 |
| `TriggerAlarm` | 设置报警、禁用轴并清除回零标记 |
| `ResetAlarm` | 清除报警和回零标记，保留当前使能状态 |
| `EnableMotor` | 检查报警互锁后使能当前轴 |
| `DisableMotor` | 禁用当前轴 |
| `CanMove` | 检查方向、速度、步数、报警、使能、回零和软件限位，返回是否允许移动 |
| `ShowMenu` | 显示当前轴和操作菜单 |
| `ShowStatus` | 显示当前轴的使能与报警状态 |
| `ShowMotionStatus` | 显示当前轴的运动状态 |
| `SelectAxis` | 校验并切换当前轴 |
| `HomeMotor` | 检查报警和使能状态，执行模拟回零 |
| `MoveMotor` | 设置 busy、调用 UpdatePosition 更新位置，再清除 busy 并报告完成 |
| `UpdatePosition` | 根据方向和步数更新位置 |
| `ShowAllPosition` | 汇总 8 个轴的位置与全部状态 |
| `main` | 初始化各轴状态、处理菜单及移动前校验 |

## 当前范围与限制

- 本项目不连接 PLC、运动控制卡或真实电机；回零只是直接将位置设为 0，不包含寻找原点开关等硬件过程。
- 速度参数用于校验与输出，不决定实际执行时间；程序没有实时调度、加减速轨迹或硬件反馈。
- 状态只保存在内存中，退出后不会保存，下次启动需重新回零。
- 尚未处理非数字输入、输入结束和整数溢出；请按示例输入有效整数，避免使用极大数值，正常退出请使用菜单 `0`。
- `CurrentAxis()` 本身不检查轴号边界；当前菜单通过初始轴号 `1` 和 `SelectAxis()` 的 1～8 校验保证有效轴号。后续扩展调用入口时需要在访问数组前校验。
- `CanMove()` 当前不检查 `busy`。同步执行模式下菜单无法在运动中处理新指令；若增加异步运动，需要补充忙碌状态互锁。
- 本版 `targetPosition` 已在 `CanMove()` 内初始化为 `0`；仍需后续完善极大步数导致的整数溢出检查。
